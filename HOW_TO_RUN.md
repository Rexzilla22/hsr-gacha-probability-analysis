# How to Run the Project

## Requirements

- Python 3
- Jupyter Notebook or Google Colab
- NumPy
- Pandas
- Matplotlib

## Google Colab Instructions

1. Open Google Colab.
2. Upload `HSR_Gacha_Probability_Project.ipynb`.
3. Select Runtime → Run all.
4. Wait for all cells to finish executing.
5. Review the tables, calculations and visualisations.

## Local Installation

Install the required libraries using:

pip install -r requirements.txt

Then open the notebook using Jupyter Notebook.

## Reproducibility

The notebook contains the probability calculations and Monte Carlo simulation.

Simulation results can vary slightly because random outcomes are generated during each run.
