# The Mathematics of Gacha Systems: Honkai: Star Rail

## Project Overview

This project analyses the probability mechanics behind the Character Event Warp system in Honkai: Star Rail.

It explores how base probabilities, soft pity, hard pity and the featured character guarantee influence the chances of obtaining a 5-star character.

## Research Question

How do pity mechanics and different saving scenarios affect the probability of obtaining a 5-star character in Honkai: Star Rail?

## Methods

The project combines mathematical probability calculations with Monte Carlo simulations.

The analysis includes:

- Theoretical probability calculations.
- A simplified soft-pity model.
- The 50/50 featured character system.
- The guaranteed featured character mechanic.
- Simulations of 100,000 players.
- A comparison of F2P, Monthly Pass and Monthly Pass + Battle Pass scenarios.
- An analysis of approximate pull costs.

## Tools

## Project Structure

`HSR_Gacha_Probability_Project.ipynb`

Contains the calculations, simulations, visualisations and conclusions.

## Limitations

The soft-pity and 4-star probability models are simplified approximations. The results should therefore not be interpreted as exact predictions of the in-game system.
