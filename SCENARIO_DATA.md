# Saving Scenario Data

## Overview

This document records the estimated Version 4.5 resources used in the project.

These figures are estimates based on the selected reward data and are not guaranteed recurring monthly income.

## Scenarios

| Scenario | Stellar Jade | Special Passes | Jade Pulls | Total Pulls |
|---|---:|---:|---:|---:|
| F2P | 9,255 | 15 | 57 | 72 |
| Monthly Pass | 11,810 | 15 | 73 | 88 |
| Monthly Pass + BP | 12,490 | 19 | 78 | 97 |

One pull costs 160 Stellar Jade.

## Calculation

The number of complete Jade-funded pulls is calculated using:

Stellar Jade / 160

Only complete pulls are counted. Any remaining Stellar Jade is excluded.

Special Passes can be used for Character Event Warp pulls.

Standard Passes are excluded because they cannot be used for the limited Character Event Warp.

## Limitations

The scenarios represent estimated Version 4.5 rewards. Actual resources depend on the version, available events and player activity.
